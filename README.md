# Ore Benedetta – interfaccia

Pagina statica dell'app di famiglia «Ore Benedetta», pubblicata con GitHub Pages:
https://manueleaufiero.github.io/ore-app/

Non contiene dati personali: nomi, ore e importi arrivano al momento dall'API (Google Apps Script) indicata in `config.js`.
Il codice sorgente dell'app sta in un repository privato; questo contiene solo il file costruito (`index.html`).
